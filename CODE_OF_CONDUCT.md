# Code of conduct

Amara Unfold contributors must make participation respectful, safe, and useful.
Harassment, intimidation, discrimination, sexualized conduct, deliberate
misgendering, publication of private information, and sustained disruption are
not acceptable in project spaces.

Be precise and kind in review. Critique code and evidence, not people. Respect
that test archives may describe highly personal lives: never ask a contributor
to publish real mail, banking, location, diary, or media data to prove a bug.
Use minimal synthetic reproductions.

Maintainers may edit or remove contributions, comments, or accounts that breach
these rules. Enforcement decisions should be documented privately, be
proportionate, avoid conflicts of interest, and protect reporters from
retaliation. A private conduct-reporting channel must be named alongside the
security channel before the first public release; until then, public launch is
blocked rather than forcing reporters to disclose sensitive details publicly.

This policy applies in repositories, issue trackers, review systems, community
spaces, and public interactions where someone represents the project.
